● Mosquitto Charm Plan

  Configuration Options

  - port: MQTT port (default: 1883)
  - websockets-port: WebSocket port for MQTT over WebSockets (default: 9001)
  - max-connections: Maximum client connections (default: -1, unlimited)
  - message-size-limit: Maximum message size in bytes (default: 268435456)
  - allow-anonymous: Allow anonymous connections (default: false)
  - log-level: Logging level (default: "notice")
  - persistence: Enable message persistence (default: true)
  - persistence-location: Directory for persistent data (default: "/var/lib/mosquitto/")

  Authentication & Security

  - auth-plugin: Authentication plugin to use
  - tls-enabled: Enable TLS encryption (default: false)
  - tls-port: TLS MQTT port (default: 8883)
  - cafile: Path to CA certificate file
  - certfile: Path to server certificate file
  - keyfile: Path to server private key file

  Actions

  - restart: Restart Mosquitto service
  - reload-config: Reload configuration without restart
  - get-status: Get broker status and statistics
  - list-clients: List connected clients
  - clear-persistence: Clear persistent message store

  Relations

  - tls-certificates: Integrate with TLS certificate providers
  - logging: Integrate with logging/observability charms
  - ingress: Expose MQTT via reverse proxy for WebSocket connections

  Scaling

  - Single-unit deployment (MQTT brokers typically don't cluster)
  - Can integrate with load balancers for multiple independent brokers
  - Persistence storage should be on local disk or mounted storage
